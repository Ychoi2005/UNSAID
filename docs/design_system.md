# Design system

Midnight navy (#10182B), indigo (#1B2340), lavender (#A99BCB), cream (#F4EEE8), rose (#D4A6AE) and gold (#DCC79A) guide a low-light room aesthetic. Brighter variants support text legibility. Georgia headings and system sans-serif body text require no font requests.

A fixed desktop sidebar becomes a compact mobile navigation. Writing has a single large textarea, optional title and tags, a draft status and explicit actions. Future features are labelled as unavailable. The home screen uses CSS stars and an original inline SVG constellation, not remote imagery.

Focus indicators, labelled inputs, a skip link, keyboard-contained confirmation dialogs and responsive layouts support accessibility. Motion respects both the system preference and the local preference; no sound is used. Automated checks cover basic keyboard and reduced-motion use, but a full WCAG audit and assistive-technology review remain outstanding.
