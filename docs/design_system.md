# Editorial design system

UNSAID is composed as a small literary publication: narrow navigation, numbered spaces, precise rules, generous margins and expressive typography. The earlier gradient/card layout has been replaced. No three-card marketing hero, glass panels, emoji navigation or invented personal writing is included.

## Palette and type

Warm paper #F4F0E8 and ivory #FAF7F1 dominate writing and browsing. Midnight ink #101522 anchors the navigation, vault identity and night-sky experience; faded navy #1D2638 supports stars. Dusty lavender #A79CBF, rose #C9A5A6 and antique gold #D4BC8C are restrained accents, not large gradient fields. Foreground values are adjusted for legibility; automated axe checks complement contrast review, not a full WCAG audit.

Georgia/Times serif headings and reading text provide editorial character with no font requests or licensing ambiguity. System sans-serif labels and controls provide a separate functional voice. Text inputs are native and labelled. The long-form surface uses comfortable serif leading and a bounded line width.

## Distinct but connected spaces

The Quiet Room has one writing action and a small CSS midnight window. The paper editor prioritizes text over tooling. Letters use a folded-paper collection and optional openings. Timeline uses month headings and a fine chronological rule. Archive uses typographic rows and quiet metadata. Perspective Shift presents three questions-as-choices, not a conversation. Constellation uses restrained cross/diamond star glyphs, thin lines and user labels; no diagnosis or automated interpretation appears.

## Interaction and access

Mobile navigation exposes the complete set of sections through a labelled menu. Native modal dialogs manage focus, return focus and Escape. Save, error and loading states have semantic status/alert roles. Cmd/Ctrl+S saves. Draft failures invoke route/close guards. Graph alternatives include list reading, connection forms, theme assignment and numeric positioning. Zoom/pan controls and graph keyboard features are supplied by XYFlow.

Only a short room entrance and envelope closure animate. System reduced motion or the local motion switch disables them. There is no sound, automatic prompt carousel, emotional score, streak or interrupting text analysis. Manual screen-reader and broad device review remain future work.
