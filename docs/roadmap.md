# Roadmap

## Implemented local prototype

Editorial redesign, all seven sections, encrypted local vault/drafts/metadata, manual and inactivity lock, passphrase changes, explicit legacy migration, encrypted backups and import, letters, real interactive constellation and alternatives, archive/timeline, static optional reflections, deletion controls and responsive navigation.

## Before sensitive use

Independent cryptography and data-flow review; deployment hardening and supply-chain review; manual screen-reader/keyboard validation and broader device/browser coverage; import/migration fuzzing and recovery drills. No independent review has been completed.

## Later engineering opportunities

Optimize whole-document draft writes for larger collections, add reviewed conflict-resolution UX, improve backup portability and version migration, evaluate native-offline installation and memory-hard KDF options. These are opportunities, not currently working features. No AI, social layer, diagnosis system or engagement-scoring feature is planned by default.
