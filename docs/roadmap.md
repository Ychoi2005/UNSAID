# Roadmap

- Phase 1: foundation, navigation and responsive visual identity — implemented.
- Phase 2: writing, one draft, persistence, edit and individual deletion — implemented.
- Phase 3: passphrase vault, encrypted storage, lock/unlock, backup import/export, clear all data and security tests — required before sensitive use.
- Phase 4: never-sent letters and envelope interactions.
- Phase 5: XYFlow/D3 constellation, user-created edges and themes, positions, filtering and accessible list alternative.
- Phase 6: static, optional reflection prompts and full reflection timeline.
- Phase 7: further accessibility, performance, browser compatibility, security review and documentation polish.

Current limitations: single draft; single-tab editing assumption; no offline installation; no encryption or backups; no completed accessibility/security audit. Future features must not silently add analysis or transmission of writing.
